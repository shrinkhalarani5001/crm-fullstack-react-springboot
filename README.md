# CRM Full Stack Application

A complete Customer Relationship Management (CRM) application built using React and Spring Boot.

## Technology Stack

### Frontend
- React
- Vite
- React Router
- Axios
- JavaScript
- Responsive CSS

### Backend
- Java 21
- Spring Boot
- Spring Web
- Spring Data JPA
- Hibernate
- REST APIs

### Database
- H2 Database

## Features

- User Login
- Create Account
- Forgot Password
- Dashboard
- Customer Management
- Lead Management
- Deal Management
- Sales Pipeline
- Task Management
- Reports
- Notifications
- User Profile
- Profile Photo Upload
- Application Settings

## CRM Pipeline

Deals move through the following stages:

1. Prospecting
2. Qualification
3. Proposal
4. Negotiation
5. Closed Won
6. Closed Lost

## Purpose

This project demonstrates a full-stack enterprise CRM application with a React frontend, Java Spring Boot backend, REST API integration, JPA/Hibernate persistence, and database connectivity.
